# Market of Abu - Curated Fashion & Lifestyle Marketplace

Market of Abu adalah platform e-commerce dan marketplace fashion modern, elegan, dan terkurasi dengan dukungan penuh bilingual (**Bahasa Indonesia 🇮🇩** & **English 🇬🇧**).

## ✨ Fitur Utama (Key Features)

- 🌐 **Dukungan Bilingual (ID & EN)**:
  - Toggle bahasa instan di header (`ID 🇮🇩` | `EN 🇬🇧`).
  - Terjemahan dinamis otomatis untuk seluruh konten website (navigasi, produk, keranjang belanja, formulir checkout, notifikasi).
  - Format mata uang dinamis (Rupiah `Rp` & USD `$`).

- 📸 **Kurasi Foto Resolusi Tinggi**:
  - Foto produk dan banner editorial beresolusi tinggi pilihan dari Unsplash.

- 🛍️ **Keranjang Belanja Interaktif (Slide-out Cart Drawer)**:
  - Atur kuantitas item (`+` / `-`), hapus produk, dan hitung subtotal & total otomatis.
  - **Sistem Kupon Diskon**: Masukkan kode promo `ABUHEMAT` atau `SUMMER50` untuk mendapatkan diskon 50% instan.

- 🔍 **Pencarian Live & Filter Kategori**:
  - Pencarian real-time berdasarkan nama produk atau brand.
  - Filter kategori: Semua, Pakaian Wanita, Pakaian Pria, Sepatu & Sneakers, Aksesoris & Tas.
  - Urutkan produk (Termurah, Tertinggi, Rating).

- 👁️ **Modal Quick View Detail Produk**:
  - Tinjau foto produk, varian ukuran (S, M, L, XL), warna, dan ulasan bintang.

- ❤️ **Sistem Wishlist (Favorit)**:
  - Simpan produk impian dengan tombol hati interaktif dan drawer favorit.

- 💳 **Modal Checkout & Pembayaran**:
  - Formulir informasi pembeli dan alamat pengiriman.
  - Opsi metode pembayaran: QRIS Instant, E-Wallet (GoPay/OVO), Virtual Account BCA/Mandiri, dan Kartu Kredit.
  - Konfirmasi pesanan dengan nomor Order ID unik.

- ⏳ **Real-Time Countdown Flash Sale**:
  - Timer promo detik-demi-detik yang aktif secara real-time.

- 🔔 **Toast Notifications**:
  - Notifikasi melayang elegan saat item ditambahkan, kupon diaplikasikan, atau bahasa diganti.

## 🚀 Cara Menjalankan (Getting Started)

Cukup buka file `index.html` langsung di browser Anda (Google Chrome, Microsoft Edge, Safari, Firefox), atau gunakan ekstensi Live Server / HTTP server lokal:

```bash
# Menggunakan npx serve
npx serve .

# Atau menggunakan python
python -m http.server 8000
```
